# 产品路线图

路线图表示方向，不是交付日期或已完成功能的承诺。先使一个新手能够控制成本、完成一个短片，再扩展复杂能力。

## 首版范围

- 定方案 / 定形象 / 做成片三个工作区；四类输入模板与分阶段问答，每轮最多三问。
- 制作方案、关键形象、分镜草稿三道确认。
- 按角色/产品/场景管理参考图，并按实际生成模式组织提示词。
- 可选的风格参考，可上传或复用，不强制付费生成。
- 项目与镜头关联的真实任务状态、收费批次确认、暂停和查询恢复。
- 自然语言提出修改建议，确认影响范围后局部重做；比较与恢复已有版本。
- 先选择一个正式镜头试拍；运动修改只重做视频，身份/构图修改才重做静帧。通过的试镜直接入片，余下每批默认最多三镜，可调整上限。
- 静态分镜草稿与最终无声 MP4 分开导出。
- 独立目录、配置、启动器与测试，不改变原小说工作台。

## 上线前验证门槛

以下事项必须记录真实结果，不能用模拟测试代替：

1. 文字服务真实连通性与结构化返回；长文本、缺失信息、无效 JSON、超时的实际表现。
2. 用户明确授权的最小即梦测试批次：一个候选参考图、一个带参考的分镜图和一个短视频；记录实际任务数、平台扣费、等待情况和画面偏差。
3. 本机导出文件的画面比例、总时长、无声状态、镜头顺序及可播放性。
4. 原工作台和新工作台同时运行，任务、配置与浏览器草稿不串用。
5. 三位无 AI 视频经验者试用，至少两位能够独立完成、修改一个镜头并下载，按 [试用表](USER-TRIAL.md) 留下证据。

配置缺失、未获批付费生成或没有实际试用者时，相应项目应标记“未验证”，而不是“通过”。

## 下一阶段候选

- 更清楚的方案对比、情绪节奏调整和画面连贯性检查。
- 在上游确实提供报价时显示可核实费用；用户预算上限与停止规则。
- 常用角色/产品素材库、跨作品复用及来源授权记录。
- 上游模式能力检测和小批次质量评估；不自动切换到额外收费服务。
- 更完整的任务备份、可恢复导入与旧版本清理向导，删除前展示影响。
- 根据三人试用结果减少术语、无效点击和无法理解的错误提示。

## 暂不纳入首版

配音、字幕、音乐、自动唇形、联网事实搜集、公众网站、账号权限、多用户协作和收费系统。没有确定需要之前，不将这些功能混进主创作流程。

## 永远不承诺

不保证绝对人物一致、一定一次满意、不会排队、固定费用或固定完成时间。优化工作流可以减少返工，不能消除云端算力限制或生成模型的不确定性。
