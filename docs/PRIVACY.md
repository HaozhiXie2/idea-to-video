# 隐私与安全边界

## 数据发送的时机

- 创建项目、上传参考图、选择版本、批准方案与本地合成：操作发生在本机。
- 点击文字分析或语言修改：相关原文、回答、方案或镜头描述会发给你配置的文字服务。它可能收费，保留期限与训练使用政策取决于该服务。
- 确认即梦生成批次：当前提示词与所引用的图像等素材会提交给即梦。上传到本机的素材不会在“上传”动作本身自动提交平台，但后续引用生成时会离开本机。
- 登录：即梦官方授权流程会与平台通信，设备码和授权凭据只供你本人使用。

不默认采集分析遥测，不建设公众账号系统。项目源码公开不等于你的作品公开；生成服务也并非“全部本地运行”。

## 本机隔离

每个项目的配置、素材、任务、媒体版本通过本机项目标识关联。新产品使用独立根目录、7862 端口、服务标识、浏览器草稿键和即梦运行 HOME，不读取旧小说项目路径或复制凭据。

这不是操作系统级安全沙箱。拥有同一 Windows 账户或磁盘权限的其他程序，仍可能读到配置与素材；使用共享电脑时请保护系统账户和磁盘。API 密钥不返回浏览器，但仍存放于本机配置，不能声称已经加密保险库化。

工作台仅监听 `127.0.0.1`，有来源/主机和请求令牌检查；不提供互联网级身份认证。不得开放公网端口、使用公共反向代理或作为多用户托管服务。

## 费用保护不是退款保证

提交前展示实际任务数量和“费用未知”提示；重复操作通过请求标识去重。不确定结果只允许查询核实，不自动重试生成。网络故障可能发生在平台已收费、客户端尚未收到任务号之间，因此任何工具都不应凭超时就断言“没有扣费”。

暂停只影响尚未提交的任务。账号费用、内容审核、排队、退款及并发限制由上游服务负责。

## 内容与模型边界

小说正文、用户输入和模型回复都是待处理数据，不得变成程序执行指令。模型返回需要结构验证，用户仍需确认关键节点。自动验证不能穷尽事实错误、隐含产品承诺、人物差异和意外画面。

请只使用自己拥有权利或得到许可的文字、人物照片、商品素材；对未成年人、他人隐私、商业秘密和敏感信息谨慎上传。不要冒用真实人物身份，不要使用本项目规避平台审核。

## 公开发布自检

不要提交 `.local/`、`.tools/`、数据目录、原文、生成作品、模型、虚拟环境、日志、密钥、登录设备码。截图必须来自实际界面且没有密钥、账户资料或未经许可的素材。仓库检查脚本与 `.gitignore` 是辅助，不替代人工审查。

发现敏感信息泄露时，先撤销或轮换凭据；从最新提交删除文件并不会自动从 Git 历史及已有克隆中消除秘密。
