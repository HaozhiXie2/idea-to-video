# 三人新手试用验证表

状态：**待真实参与者执行**。开发者走查、离线测试、录制演示不能替代本试验。不要填写虚构姓名、耗时、成功率或反馈。

## 目标

邀请三位此前不会制作 AI 视频的人，至少两位在不由开发者代操作的情况下，独立完成一部短片、修改一个镜头并下载成片。可以阅读产品内说明；若需要旁人指导，记录指导内容，不将其计为完全独立完成。

## 准备

- 由项目持有人完成一次服务配置与授权，不要求试用者研究 API。
- 提供获准使用的素材，建议 15 秒竖屏任务以限制测试成本。
- 每位试用者开始前知道可能发生文字服务费和即梦生成费；每个媒体批次仍由其确认。
- 提醒不得输入真实敏感资料。记录用匿名代号 A/B/C，不收集无关个人信息。
- 云端排队与用户实际操作用时分开记录；排队失败不归咎于试用者。

## 统一任务

“请把你自己的一个想法做成 15 秒短片。确认方案、关键形象与分镜。完成后找一个不满意的镜头，用普通话提出修改，只重做必要内容，再下载最终无声 MP4。”

主持人只能在安全、费用误操作或明显故障时干预。不要提前告诉试用者每个按钮的位置。

## 每人一份记录

复制以下内容三次，测试后将含个人信息的原始记录保留在私人位置；公开仓库只放已授权、匿名的汇总结论。

- 试用者代号：待填
- 日期、软件提交版本：待填
- 使用模板与目标：待填
- 是否事先具有 AI 视频经验：待填
- 能否理解“制作方案 / 关键形象 / 分镜草稿”：待填
- 是否独立走完三个确认点：待填
- 是否理解本次生成数量与费用未知提示：待填
- 第一次卡住的位置与原话：待填
- 语言修改是否作用于预期镜头：待填
- 是否发现其他镜头被不必要重做：待填
- 是否能比较新旧版本并恢复：待填
- 是否成功下载并播放最终无声 MP4：待填
- 实际操作时间 / 云端等待时间：分别待填
- 实际平台费用或“未能查证”：待填
- 主持人介入次数与具体原因：待填
- 是否独立达成目标：通过 / 未通过 / 因外部故障未完成
- 最想改进的一件事：待填

## 验收与处理

满足至少 2/3 独立完成后，记录版本与关键问题，仍不宣称所有新手都能成功。若不足 2/3，优先修复共同卡点，再用新的真实尝试复测。由于缺少密钥、额度、网络或模型不可用中断时，明确记录外部条件，不能计为功能通过。
