# 灵感影坊 · Idea to Video

把一句想法或一段正文，变成可以逐镜修改的短视频。

这是面向 AI 视频新手的**本地创作工作台**，不是一键保证出片的魔法按钮。界面收拢为 **定方案 / 定形象 / 做成片** 三个工作区。制作方案、关键形象、分镜草稿仍分别审核；视频先试一个正式镜头，满意后再生成剩余镜头。

新项目独立于 [novel-storyboard 小说改编工作台](https://github.com/HaozhiXie2/novel-storyboard)：使用自己的目录、运行环境、设置、素材和任务记录，默认地址为 **http://127.0.0.1:7862/**。原小说项目的 7861 工作台不需要修改。

## 先了解使用条件

- Windows 10/11 x64，Python 3.12 或更高版本。图像和视频由云端生成，本机不需要运行大模型；本地仅负责界面、文件管理和视频合成。
- 一个可用的 **Chat Completions 兼容文字服务**：服务地址、模型名、API 密钥。缺少配置时，会明确停在设置步骤，不拿演示内容冒充分析。
- 即梦官方创作 CLI 和你自行完成的独立授权。生成能力、会员权益、费用与排队情况由平台决定。
- **文字服务与即梦是两项独立配置，也可能分别收费。** 即梦会员不自动提供另一个文字服务的 API 密钥。

当前是本机小范围试用版本。离线测试不等于真实云端验收；未经明确测试批次授权，不会自动生成付费样片。三人新手可用性试验尚需实际参与者，记录方法见 [试用验证表](docs/USER-TRIAL.md)。

## 开始使用

1. 将项目放在独立文件夹，不要放进原小说项目的目录。
2. 打开此文件夹的 PowerShell，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1`。
3. 运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\login.ps1`，在即梦官方页面完成本项目授权。不会导入旧项目登录凭据。
4. 双击 **Start-Studio.cmd**，打开 `http://127.0.0.1:7862/`。
5. 在页面设置里填写文字服务配置；不要把 API 密钥发到聊天、截图或 GitHub。

详细安装、网络排错和运行环境选择见 [安装说明](docs/INSTALL.md)。只浏览界面或进行离线开发时，可以暂不登录、不填密钥；分析与云端生成会如实显示不可用。

## 一次创作如何进行

1. **讲清想法。** 选择故事剧情、产品展示、知识示意或生活纪念，输入一句话或完整正文，也可导入 TXT/MD。默认竖屏、30 秒，可选 15/30/60/90 秒。缺失信息按阶段每轮最多问三项，不在最初追问全部外貌，不擅自添加剧情、产品承诺或知识事实。
2. **确认制作方案。** 按模板检查内容骨架、风格和受众，再继续，不把四种类型都硬套成同一场戏。首版用纯无声画面表达，不依赖短台词或旁白。
3. **确定关键形象。** 按需要生成或上传角色、产品、场景参考。每次先做一个候选，满意再确认；人物面部与全身服装参考分开管理。风格样张可上传、复用或跳过，不强制额外付费生成。
4. **审核分镜。** 查看镜头顺序、动作、运镜、原文依据与提示词，先生成分镜图。可导出**静态分镜草稿**看节奏，它不是最终动态视频。
5. **先试一镜，再生成。** 确认分镜后选一个正式镜头试拍，优先 5 秒，实际按所选镜头的 5/10 秒提交。试拍通过可直接入片；剩余镜头每批默认最多 3 个，上限可调整。用日常语言提出修改，先看影响范围再应用；只改运动时不重做合格静帧，身份或构图错了才重做受影响图片。支持版本比较和恢复。
6. **导出成片。** 全部当前镜头就绪后，在本机拼接为**无声 MP4**。首版不含配音、字幕或音乐，也不会把短镜头偷偷循环成更长成片。

提示词会按任务类型组织为具体主体、动作、环境、画面风格和镜头语言；参考素材通过对应生图/视频模式传递。不同账号与模式的可用性仍需实际验证，不能仅凭提示词格式保证平台接受、人物完全一致或生成结果满意。

## 费用与失败保护

- 每批媒体生成前显示任务数量；不能获知费用时明确显示“费用未知”，由你确认后才提交。文字分析和语言修改也可能产生文字服务费用。
- 同一请求重复点击不会故意重复扣费；已提交但结果不明的任务不会自动重发。
- 暂停只阻止**后续**提交，不代表取消已在平台运行的任务，也不保证退款。
- 断线后优先查询已有任务。对于没有保存到平台任务编号的情况，需要人工核对，不把“查不到”当作“没扣费”。
- 排队只显示平台真实状态，不猜百分比、不承诺完成时间。更换项目不能提升同账号的平台额度或并发上限。

## 数据、安全与限制

素材、作品、任务记录和配置保留在本机并排除出 Git；**保留在本机不代表生成过程完全离线**。点“分析/修改”会向配置的文字服务发送相关文本；点“生成”会将提示词及所用参考素材发送到即梦。请先确认你有使用这些文字、肖像、产品图的权利。详细说明见 [隐私与安全边界](docs/PRIVACY.md)。

服务仅监听本机回环地址，不面向公网，不含账号系统、收费系统或多人权限隔离。不要把 7862 端口映射到公网。密钥属于本机敏感文件；本项目不替代操作系统账户安全或磁盘加密。

参考图、预览审核、局部重做可以减少偏差，但无法保证绝对角色一致、科学事实正确、文字排版正确或一遍满意。对产品参数、知识内容与人物肖像仍需人工审核。

## 项目与开发

代码主要位于 `app/`；`scripts/` 提供独立安装、启动与登录；`tests/` 是不连接真实云服务的测试；`docs/` 是安装、隐私、路线图与试用记录。作品保存在 `data/projects/`，配置保存在 `.local/config.json`；`.local/`、`.tools/` 和 `data/` 都不属于公开代码。

开发验证：

```powershell
python -m unittest discover -s tests -p "test_*.py" -v
node tests/test_ui.cjs
python scripts/check-repo.py
```

Node.js 仅用于前端离线测试，日常打开工作台不需要它。测试中使用受控模拟返回，不代表已经完成真实文字模型、即梦付费生成或用户试验。
